HackClub

The global club behind our club.

Husky Tech is an official Hack Club chapter. Hack Club is a global network of student coding clubs and a registered 501(c)(3) non-profit. It provides event funding, hardware grants, physical rewards and competitive hackathon backing.

YSWS

You Ship, We Ship.

Husky Tech runs on Hack Club's YSWS initiative: you ship production-grade projects, and you receive hardware, tools and project backing in return.

You build

Members engineer real software and hardware projects.

You ship

Deploy it publicly and submit it to a Hack Club program.

They ship back

Earn physical rewards, developer infrastructure, microcontrollers, grants and fabrication equipment like 3D printers.
