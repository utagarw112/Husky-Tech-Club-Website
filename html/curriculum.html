Community mentorship & technical leadership

Members become engineering leads and teach middle school students to code, build hardware and ship their first projects. Phase 1 covers curriculum design, debugging assistance, architecture coaching and workshop management.

Module 1

Frontend Architecture & Portfolios

Mentees build responsive personal portfolio sites with standard web technologies and publish via Bake Sale / Boba Drops.

Module 2

Interactive Systems & Game Development

Mentees build interactive software and playable game logic: control loops, state logic and event handling, via Hack Club Arcade.

Module 3

Embedded Electronics & Physical Computing

Mentees wire sensors, displays and physical inputs to microcontrollers and ship real embedded hardware through Orpheus.
